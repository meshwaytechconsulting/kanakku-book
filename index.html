📖 AI Setup Guide — Local LLM & Cloud AI

🦙 1. Free Local LLM Setup (Ollama & Llama 3.2) 100% Free & Private

Run powerful AI models (Meta Llama 3.2, Mistral, Phi-3) completely free on your computer without sharing data over the internet.

Step 1: Download & Install Ollama from https://ollama.com/download 🔗
Step 2: Open your terminal (Command Prompt / PowerShell / Mac Terminal) and run: 
ollama run llama3.2
Step 3: Configure Kanakku Book AI Connection Settings:
  • AI Provider Engine: Select Local LLM (Ollama / LM Studio)
  • Server Base URL: http://localhost:11434/v1
  • Model Name: llama3.2
  • API Key: Leave empty
Step 4: Click 🔍 Test Connection in Settings to confirm green latency indicator!
💡 Alternative (LM Studio): Download from https://lmstudio.ai 🔗, load Llama 3.2, start local server, and set Base URL to http://localhost:1234/v1.
♊ 2. Google Gemini Setup (Free Tier Available)
Step 1: Get a free Gemini API Key from Google AI Studio: Get Gemini Key 🔗
Step 2: Configure Settings:
  • AI Provider Engine: Select Google Gemini API
  • API Key: Paste your AIzaSy... key
  • Model Name: gemini-1.5-flash (Fast & Free) or gemini-1.5-pro
🧠 3. Anthropic Claude Setup
Step 1: Obtain an API Key from Anthropic Console: Get Claude Key 🔗
Step 2: Configure Settings:
  • AI Provider Engine: Select Anthropic Claude API
  • API Key: Paste your sk-ant-... key
  • Model Name: claude-3-haiku-20240307 or claude-3-5-sonnet-20240620
⚡ 4. OpenAI ChatGPT Setup
Step 1: Generate an API Key from OpenAI Platform: Get OpenAI Key 🔗
Step 2: Configure Settings:
  • AI Provider Engine: Select OpenAI / Groq / DeepSeek
  • Base URL: https://api.openai.com/v1
  • Model Name: gpt-4o-mini or gpt-4o
